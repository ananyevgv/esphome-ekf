Умный контроллер для автоматизации оконных и климатических систем в помещении. Проект объединяет управление:

Шторами/жалюзи (два устройства Tuya MB60L в разных зонах)

Увлажнителем воздуха (Smartmi на базе протокола MIoT)

Освещением (аквариум и декоративная подсветка)

Аппаратная платформа
Микроконтроллер: ESP32-S3-Zero Mini

Распиновка (ключевые выводы):

Реле 1-5: GPIO 6,5,2,1,7

Светодиод WS2812: GPIO3

Кнопка управления: GPIO4

I2C (для датчиков): SDA=8, SCL=9

Tuya MB60L: две пары UART (GPIO12/13 и GPIO10/11)

Увлажнитель MIoT: UART (GPIO44/43)

Основные функции
1. Автоматизация освещения и фильтрации
Свет аквариума включается на закате (реле 3)

Фильтр аквариума работает по расписанию: 9:00 – 23:00 (реле 4)

Управление RGB-светодиодом для индикации статуса

2. Управление жалюзи (два независимых канала)
Интеграция с моторами Tuya MB60L через UART

Автоматическое открытие:

В рабочие дни в 7:00 (если солнце уже над горизонтом)

В выходные в 9:00

Закрытие на закате

Управление положением, скоростью, защитой от детей

Режим наклона ламелей

3. Увлажнитель воздуха
Управление Smartmi Evaporative Humidifier 2

Мониторинг: температура, влажность, уровень воды, скорость мотора

Дополнительные режимы: сушка, очистка, блокировка от детей

4. Сценарии с одной кнопки
Короткое нажатие (<0.5с): включение всех реле 

Длинное нажатие (>1с): выключение всех устройств

Веб-интерфейс и API
Локальный веб-сервер (порт 80) с авторизацией

Home Assistant API с шифрованием

OTA-обновления прошивки

Мониторинг WiFi (сигнал в dBm и %)

Датчики и автоматизация
Вычисление следующего события солнца (восход/закат)

Распознавание рабочих/выходных дней через Home Assistant

Статус подключения к HA

Безопасность
Все секреты вынесены в !secret (пароли, ключи, SSID)

WPA2 для WiFi

Отдельная авторизация для веб-интерфейса

Структура проекта

```
esphome-ekf/
├── RCE-1/
│   ├── holl-window.yaml       # Основной конфиг
│   └── packages/              # Модульные компоненты
│       ├── wifi.yaml          # WiFi + API + OTA
│       ├── device_base.yaml   # Базовая конфигурация
│       ├── web.yaml           # Веб-сервер
│       ├── time.yaml          # SNTP (UTC-3)
│       ├── sun.yaml           # Положение солнца
│       ├── Tuya_MB60L.yaml    # Драйвер жалюзи
│       └── humidifier2.yaml   # Драйвер увлажнителя

```

Секреты: secrets.yaml с параметрами WiFi, API, OTA, географическими координатами

Пример использования
Идеально для автоматизации "умной квартиры", где нужно синхронизировать открытие штор с рассветом, поддерживать влажность воздуха и управлять аквариумом по расписанию – всё через единый контроллер.
